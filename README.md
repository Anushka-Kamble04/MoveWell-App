# MoveWell Physiotherapy & Rehabilitation

MoveWell is a responsive physiotherapy clinic website built as a frontend project using HTML, CSS, and JavaScript.

The website is designed for a fictional physiotherapy clinic based in Aundh, Pune. It focuses on presenting the clinic's services, rehabilitation team, appointment process, and contact information in a clean and user-friendly layout.

## Features

* Responsive design for desktop, tablet, and mobile
* Mobile navigation menu
* Smooth scrolling
* Back-to-top button
* Appointment booking modal
* Client-side form validation
* Preferred date and time restrictions
* Appointment request success message
* Contact links
* Responsive service and team sections

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Git & GitHub
* GitHub Pages
